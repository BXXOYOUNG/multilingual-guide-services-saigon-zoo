"""Create a one-time administrator in the development database if none exists."""
import asyncio
import os
import secrets
from datetime import datetime, timezone

from pymongo import AsyncMongoClient

from backend.services.admin_auth import hash_password


async def main():
    uri = os.environ.get("MONGODB_URI")
    database_name = os.environ.get("MONGODB_DATABASE")
    if not uri or not database_name:
        raise SystemExit("Set MONGODB_URI and MONGODB_DATABASE first.")
    client = AsyncMongoClient(uri)
    try:
        db = client[database_name]
        if await db["admin_users"].count_documents({}):
            print("An administrator already exists; no database changes made.")
            return
        now = datetime.now(timezone.utc)
        role = await db["roles"].find_one({"name": "administrator"})
        permissions = ["poi:write", "content:write", "audio:write", "analytics:read"]
        if role:
            role_id = role["_id"]
            await db["roles"].update_one({"_id": role_id}, {"$set": {"permissions": permissions, "updated_at": now}})
        else:
            role_result = await db["roles"].insert_one({"name": "administrator", "description": "Full access to the zoo guide demo admin area", "permissions": permissions, "created_at": now, "updated_at": now})
            role_id = role_result.inserted_id
        password = secrets.token_urlsafe(24)
        await db["admin_users"].insert_one({
            "username": "demo-admin",
            "email": "demo-admin@localhost.invalid",
            "password_hash": hash_password(password),
            "role_id": role_id,
            "is_active": True,
            "last_login": None,
            "created_at": now,
        })
        print("One-time demo admin created in saigon_zoo_tcv_dataset_dev.")
        print("username=demo-admin")
        print(f"password={password}")
        print("Store this password securely; it is not written to disk.")
    finally:
        await client.close()


if __name__ == "__main__":
    asyncio.run(main())
